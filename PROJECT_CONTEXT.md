# Kontekst projektu

Photo Face Finder to prywatna aplikacja desktopowa dla użytkownika Windows, który chce odnaleźć zdjęcia zawierające wskazaną osobę i skopiować je do drugiego folderu.

## Dla kogo

Dla osoby porządkującej własne archiwum zdjęć, posiadającej zgodę osoby przedstawionej na fotografiach wzorcowych.

## Problem

Ręczne przeglądanie dużej liczby zdjęć grupowych jest czasochłonne. Aplikacja wykrywa wszystkie twarze na każdym zdjęciu i uznaje zdjęcie za trafienie, jeżeli przynajmniej jedna twarz pasuje do wzorca.

## Granice

- Program nie nazywa ani nie profiluje osób.
- Nie tworzy trwałej bazy twarzy.
- Nie służy do monitoringu, identyfikacji w czasie rzeczywistym ani zastosowań wysokiego ryzyka.
- Nie modyfikuje oryginalnych zdjęć i nie usuwa plików.
- Tryb OpenAI jest eksperymentalny, płatny i dostępny tylko po potwierdzeniu zgody.
